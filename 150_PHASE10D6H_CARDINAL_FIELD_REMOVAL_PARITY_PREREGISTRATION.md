# Phase 10D.6H — Cardinal-Field Removal Parity Shadow

**Status:** PREREGISTERED / NO 10D.6H OUTCOMES SAMPLED
**Date:** 2026-09-11

## Question

Can the three uncalibrated effect-level cardinal fields (`change_magnitude`, `epistemic_strength`, `target_importance`) be removed from Relation-Mapping output without materially changing the relation topology, once native semantics and explicit support/jurisdiction provenance are held fixed?

10D.6G established that support binding itself is compatible with historical native Relation-Mapping. The remaining schema question is whether the cardinal fields are merely diagnostic baggage or whether asking the model to emit them changes which semantic relations it emits.

## Frozen intervention

Reuse the exact 10D.6G semantic base and provenance obligations:
- exact frozen A/D/X/N4 audited worlds, Kernel fixtures, and modal Locate;
- historical `NATIVE_IMPACT_SYSTEM` semantics;
- `support_unit_ids` and `jurisdiction_anchor_ids` provenance;
- same identifier legality and deterministic relation-identity normalization;
- temperature 0.1, thinking disabled.

The only intended intervention is the effect schema:

```text
10D.6G effect
= operation + target + reason + exploration flag
  + support/jurisdiction provenance
  + change_magnitude + epistemic_strength + target_importance

10D.6H effect
= operation + target + reason + exploration flag
  + support/jurisdiction provenance
```

No replacement numeric score or threshold is introduced. Top-level compatibility response metadata remains unchanged so the gate isolates removal of the three effect-level cardinal fields.

## Sampling and decision

Run 6 fresh realizations per case, 24 calls total, no outcome-dependent expansion.

Persist structural success, identifier validity, raw/normalized relation families, support signatures, duplicate burden, and 10D.6G sentinel recovery.

If the stable 10D.6G relation families broadly survive while support validity remains comparable, the three cardinal effect fields are not required for semantic relation generation and can remain absent from the vNext semantic contract. If relation families collapse again, cardinal-field removal is itself decision-bearing and must remain a separate compatibility concern.

No Attention policy is evaluated or promoted in this gate. Production defaults remain unchanged; Phase 9A remains paused.
