## Question

Does the discrepancy enter because production Relation Mapping consumes a flattened `ExtractionResult` rather than the Auditor-admitted canonical semantic units?

## Controlled design

Use the exact Phase 10D.4 frozen real-web worlds A, D, X, N4, exact Kernel fixture, exact modal Locate, same DeepSeek Flash structured-output path, same current production `IMPACT_SYSTEM`, same current importance resolver, same production `ground_effects`, same feature projection, and same `pareto-multidelta-magnitude-free-anchored-open-new` strategy.

- **C1 / canonical:** direct Auditor-admitted semantic units (`unit_id`, statement, epistemic status, confidence, supports) plus the same Locate/eligible-target rows. No raw webpage text.

The system prompt intentionally remains the current P0 prompt in this gate; prompt reconciliation is held out so input representation can be attributed independently.

Both arms still build the same audited-units-derived `ExtractionResult` for deterministic post-LLM safeguards. Therefore targeted legality, scope checks, epistemic caps, current importance resolver and runtime semantics are unchanged.

## Instrumentation

For every realization persist both:
1. **raw LLM effects** after current Kernel importance resolution but before `ground_effects`;
2. **grounded legal effects** after production safeguards;
3. relation topology, Decision-Causal Core and article Attention.

This separates `input -> raw Relation Mapping` from `grounding -> decision`.

Sampling: N=6 per arm per case, interleaved B0/C1. No outcome-dependent expansion or prompt modification.

## Interpretation gates

- Canonical raw effects recover but grounded effects disappear -> grounding seam is causal next layer.
- Canonical raw + grounded effects recover -> `ExtractionResult` flattening is primary measured cause.
- Canonical raw effects remain empty -> representation alone is insufficient; Relation Mapping/system prompt remains causal.
- C1 must not be promoted from Attention agreement alone; semantic legality and critical false-DROP / spurious-ENGAGE behavior remain required.

Production default remains unchanged. Phase 9A remains paused.
