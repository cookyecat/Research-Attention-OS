# Phase 10D.6E — Canonical Authority Enrichment Preregistration

**Status:** PREREGISTERED / DESIGN GATE / NO POLICY PROMOTION  
**Date:** 2026-09-11

## Motivation

10D.6B–D show that prompt and input representation matter, but the remaining production/research divergence is now concentrated in decision-bearing authority after Relation Mapping. Under Magnitude-Free v0.1, raw `change_magnitude` is correctly non-authoritative, but Attention still depends on `epistemic_band`, `importance_band`, `active_role_band`, and operation.

Two unresolved authority seams are now explicit:

1. **Target importance.** Current production resolution is explicit Kernel importance/priority > fixed node-type prior > LLM estimate > neutral. With the current 0.55 binary threshold, almost every update-eligible type prior except EXPERIMENT is automatically "high", while LLM fallback remains an uncalibrated cardinal estimate.
2. **Epistemic support.** Current production `epistemic_cap` forces one-source/no-`ExtractionResult.observations` effects to <=0.35. On canonical audited worlds this can convert all surviving relations to weak support even though the Auditor has already established source-grounded sufficiency. Auditor sufficiency, however, is not outside-world truth, so the cap also cannot simply be deleted.

## Target contract

A vNext semantic CognitiveEffect should minimize LLM decision authority. Relation Mapping is responsible for:
- `operation`: REINFORCE / CHALLENGE / OPEN_NEW;
- legal target or OPEN_NEW jurisdiction;
- explicit references to supporting canonical semantic-unit IDs;
- semantic reason.

Compatibility cardinal fields may remain temporarily for diagnostics but must not determine admission, dominance, Attention, or Kernel mutation.

Deterministic enrichment then derives:
- **importance authority** from Kernel/user state and explicit jurisdiction, not raw LLM importance;
- **epistemic authority** from canonical provenance / Auditor / source-graph evidence classes, not raw LLM epistemic decimals;
- active-role information from Kernel type/state;
- target legality, Location != Update, and runtime authority from deterministic system state.

## Required separation

Auditor `SUFFICIENT` means the semantic unit is supported by its cited source evidence. It does **not** mean the source claim is externally true. 10D.6E must preserve this distinction when defining epistemic bands.

Likewise node type is not itself user importance. Type may contribute a conservative engineering prior or active-role semantics, but must not silently masquerade as calibrated per-node importance.

## Research order

1. Audit current binary-band degeneracy and sensitivity on frozen artifacts; no LLM calls.
2. Define candidate ordinal authority mappings before observing candidate outcomes.
3. Add support-unit identity to the vNext Relation-Mapping contract so deterministic provenance checks are possible.
4. Evaluate authority mappings by deterministic replay first, then a fresh canonical shadow only if needed.
5. Promotion requires no critical false DROP, no uncontrolled ENGAGE inflation, preservation of semantic legality, and no regression of known stable basins.

Production default remains unchanged. `IMPACT_SYSTEM_VNEXT` remains experimental. Phase 9A remains paused.
