# Phase 8C.8 — Semantic Topology Stability Attribution Preregistration

Status: EXPERIMENTALLY COMPLETE / SEE `92_PHASE8C8_SEMANTIC_TOPOLOGY_STABILITY_RESULT.md`
Date: 2026-09-10

## Question

Where does Semantic Topology variance enter the causal stack once raw `change_magnitude` has no decision authority?

For this phase, Semantic Topology is the set of legal cognitive relations:

```text
T(E,K) = {(operation, target)}
```

`change_magnitude`, `epistemic_strength`, `target_importance`, and Attention are attributes/downstream decisions, not topology identity.

## Cases

Eight frozen audited worlds:

- RS05 — critical CHALLENGE positive; canonical sentinel `CHALLENGE(CF-B-PERF)`.
- RS15 — genuine multi-effect case; canonical relations include `REINFORCE(Q2)` and `REINFORCE(B2)`.
- RS11 — negative/noise control.
- RS12 — weak-positive boundary case; no new gold invented.
- A/C/D/X — the four exact Phase 8C.7 real-web audited semantic worlds.

RS05/RS15/RS11/RS12 use the frozen Phase 7A Auditor artifacts. A/C/D/X use the exact admitted semantic-unit sets frozen in the Phase 8C.7 real-web artifact. No Sensor or Auditor call is made in Gate 1.

## Gate 1A — Locate stability

For each frozen audited world and exact Kernel fixture, run native Locate six times at the frozen model settings. Measure target-set stability separately from `(target, relevance_type)` stability.

After the six runs, choose the modal `(target, relevance_type)` topology. Freeze one exact representative realization of that modal set, including its scores and reasons, for Gate 1B. This selection is deterministic and uses no downstream outcome.

## Gate 1B — Cognitive Impact stability

Using the exact same frozen audited world and the exact frozen modal Locate realization, run native multi-effect Cognitive Impact six times.

Measure:

- exact coarse topology mode rate;
- mean pairwise Jaccard;
- per-edge frequency;
- critical-relation recall where a prior sentinel exists;
- topology entropy as a secondary diagnostic;
- Magnitude-Free Pareto Attention stability.

Magnitude-Free v0.1 and Pareto v0.1 are frozen. No threshold or policy rule may be tuned after results.

## OPEN_NEW measurement identity

Primary topology metrics use `(OPEN_NEW, null)` because the production effect schema has no stable branch identifier. To avoid silently conflating distinct branches, the artifact additionally records a measurement-only deterministic normalized-reason signature for each OPEN_NEW effect. This strict signature is diagnostic only: lexical paraphrases may over-split the same semantic branch, so it is not used as the headline topology KPI.

## Interpretation

If Gate 1A is unstable while Gate 1B is stable under frozen matches, attribute the dominant residual to Locate. If Gate 1B remains unstable with matches frozen, attribute it to Cognitive Impact mapping. Only if Gate 1 is sufficiently stable should the next experiment reopen Auditor/Sensor variance.

The phase does not promote Pareto or Magnitude-Free to production. Production default remains `one-delta-v1`.
